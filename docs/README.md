# GREYC Ambrosia User Guide

Start with the [package README](../README.md) and the complete
[starter](../template/template.typ). The [branding guide](branding.md) explains
GREYC flavors, palettes, team marks, logo placement, and watermarks.

The shared presentation features are documented in
[Touying Ambrosia's user guide](https://github.com/inspiros/touying-ambrosia/blob/master/docs/README.md)
and [illustrated manual](https://github.com/inspiros/touying-ambrosia/blob/master/docs/manual.pdf).
Use `greyc-theme` in place of `ambrosia-theme`; shared authoring helpers retain
the same names.

For private presenter notes, follow the core's
[speaker notes guide](https://github.com/inspiros/touying-ambrosia/blob/master/docs/speaker-notes.md).
The PDF/sidecar and split-page workflows also apply to `greyc-theme`.

Editable examples:

- [Branding](../examples/branding.typ): lab/team marks, flavors, and palettes.
- [Full Demo](../examples/demo.typ): the legacy layout with shared utilities.
- [Team Sheet](../examples/teams.typ): inspect the available marks.
- [Small Sample](../examples/sample.typ): a compact presentation.
