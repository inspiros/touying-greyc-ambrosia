# Maintainer Documentation

This section is for developing and releasing the package. Presentation authors
should use the [user guide](../README.md).

- [Contributing](../../CONTRIBUTING.md): checkout setup and common commands.
- [Development](development.md): regression coverage and branding contracts.
- [Package Boundary](package-boundary.md): the neutral core and branded wrapper.
- [Joint Release](releasing.md): preparing both packages for one submission.
- [Hero Source](artwork/hero.typ) and [Slide Specimens](artwork/slides.typ):
  editable README artwork, regenerated by
  [render-thumbnail.py](../../scripts/render-thumbnail.py).

The SVG hero is project artwork. The manifest instead uses a PNG of an
unmodified initialized legacy title slide. Runtime imports never depend on the
maintainer documentation or artwork sources.
